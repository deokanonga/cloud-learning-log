# VPC Day 4: NAT gateway and private subnets

## The problem
A database in a private subnet needs to download updates, but nobody on the internet may reach it.

## What I built
- Created a NAT gateway (deo-lab-nat, Zonal) in deo-lab-public-a with a new Elastic IP
- Added 0.0.0.0/0 -> deo-lab-nat to deo-lab-private-rt
- Deleted the NAT gateway, released the Elastic IP and removed the leftover blackhole route the same day (lab cost: about 3 cents)

## How the traffic travels
| Step | Where the packet is | Route it follows | Goes to |
|---|---|---|---|
| 1 | Database in private-a | private-rt: 0.0.0.0/0 -> NAT | NAT gateway |
| 2 | NAT gateway in public-a (swaps the private IP for its Elastic IP) | public-rt: 0.0.0.0/0 -> IGW | Internet gateway |
| 3 | Internet gateway | | Internet |

Replies come back the same way, and the NAT swaps the IP back. Nobody outside can start a connection in.

## What I learned
- NAT = Network Address Translation
- A NAT gateway must live in a public subnet, because the NAT itself needs a route to the internet gateway
- Route tables are road signs each subnet reads, not stops on the trip
- An internet gateway never hands out IP addresses; it only translates for servers that already have a public IP
- Internet gateway: two-way, free, every server needs its own public IP. NAT gateway: outbound only, paid, servers share the NAT's Elastic IP
- A NAT gateway lives in one AZ. Production uses one NAT per AZ (or the newer Regional NAT gateway) so one AZ failure doesn't cut off the other
- A NAT gateway keeps billing even when nothing uses it, and so does an unattached Elastic IP
- "Blackhole" = the route's target no longer exists, so traffic is dropped

## Breaks
| What I tried | What happened | Why |
|---|---|---|
| Pointed private-rt 0.0.0.0/0 at the internet gateway | Private subnets turned "public" on the map; NAT connected to nothing | A database with no public IP can't use the internet gateway, so its traffic is dropped. Giving it a public IP would expose it |
| Deleted the NAT gateway | Route showed Blackhole | The route's target was gone |
