# VPC Day 3: Route tables and the internet gateway

## What I built
- Created an internet gateway (deo-lab-igw) and attached it to deo-lab-vpc
- Created a public route table (deo-lab-public-rt) with 0.0.0.0/0 -> deo-lab-igw
- Associated deo-lab-public-a and deo-lab-public-b with the public route table
- Named the main route table deo-lab-private-rt (local route only) and left the private subnets on it
- Turned on auto-assign public IPv4 for both public subnets
- Added a Name tag to deo-lab-vpc so it shows by name in dropdowns

| Route table | Routes | Subnets |
|---|---|---|
| deo-lab-private-rt (main) | 10.0.0.0/16 -> local | private-a, private-b (implicit) |
| deo-lab-public-rt | 10.0.0.0/16 -> local, 0.0.0.0/0 -> deo-lab-igw | public-a, public-b (explicit) |

## What I learned
- A subnet is public only because its route table has a route to an internet gateway
- Keep the main route table private: any new subnet joins it automatically, so a forgotten step stays safe
- One internet gateway attaches to one VPC, and one VPC has at most one internet gateway
- Each subnet follows exactly one route table; associating it with a new one moves it automatically
- The local route can never be removed
- The router uses the most specific match (longest prefix match): 10.0.x.x stays local, everything else follows 0.0.0.0/0
- A server is reachable from the internet only with 3 things: a route to the IGW, a public IP, and a security group that allows the traffic
- The internet gateway translates between a server's private IP and its public IP (a NAT gateway is a different, paid service for private subnets)
- VPC Block Public Access is a region-wide guardrail, not a per-subnet switch

## Breaks
| What I tried | What happened | Why |
|---|---|---|
| Removed 0.0.0.0/0 from deo-lab-public-rt | Public subnets turned private in the resource map; IGW no longer linked to any route table | With no route to the IGW, internet traffic has nowhere to go and is dropped. Associations did not change |
| Put the route back | Public subnets public again | Route to the IGW restored |
